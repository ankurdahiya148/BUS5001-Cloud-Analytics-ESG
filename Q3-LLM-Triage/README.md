# Q3 – ESG Message Triage

This folder contains experiment logs, screenshots and outputs for the ESG operational message triage prototype implemented using Databricks and Hugging Face transformer models.

## Technologies Used
- Azure Databricks
- Hugging Face Transformers
- Zero-shot Classification
- Rule-based Baseline Classifier

## Experiments
- ESG message classification
- JSON triage generation
- Baseline comparison
- NLP workflow evaluation
